طريقة استخراج EXE تلقائياً من GitHub
====================================

1) أنشئ حساباً على https://github.com ثم أكّد بريدك الإلكتروني.
2) أنشئ مستودعاً جديداً (New repository)، واجعله Private، وسمّه مثلاً school-windows.
3) لا تفعّل إضافة README أو .gitignore أو License عند الإنشاء.
4) بعد إنشاء المستودع، اختر Add file ثم Upload files.
5) فك ضغط هذا المشروع على جهازك، وارفع كل الملفات والمجلدات الموجودة بداخله، بما فيها المجلد المخفي .github.
6) اضغط Commit changes.
7) افتح تبويب Actions في المستودع. ستجد مهمة Build Windows EXE تعمل تلقائياً.
8) بعد أن تصبح المهمة خضراء (نجاح)، افتحها ثم انزل إلى Artifacts وحمّل School-Windows-EXE.zip.
9) فك ضغط الملف الناتج وستجد ملفات EXE.

مهم:
- اترك المستودع Private ولا تنشر ملف APK أو ملفات المشروع علناً.
- لا تشارك كلمة مرور GitHub أو رموز الدخول مع أي شخص.
- هذا المسار ينشئ ملفات EXE عبر خادم Windows تابع لـ GitHub Actions؛ لا يعني ذلك أن التطبيق خضع بعد لاختبار كامل على جهاز Windows.
